# Preservation justifications for 1.6.5

One line per v1.6.5 line that is removed, changed or moved: `- <old place> :: <exact old line> :: <reason>`. This file holds the Red Flags trim of [superfix-skill#121](https://github.com/thedanielmay/superfix-skill/issues/121): 22 bullets were removed from `## Red Flags` and every rule they carried is stated at the home line named in the reason. The full map, with the quote from each home, is `out-triage/redflags-map.md` next to the handoff.

The file is named for the release it compares against, not the release it lands in, because `tests/preservation-check.py` reads `tests/preservation-<version>.md` with `<version>` from `.claude-plugin/plugin.json`, which this branch does not bump.

Check: `python3 tests/preservation-check.py "$PWD"` must print `0 unjustified` and exit 0.
